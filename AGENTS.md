# go-zulip

Unofficial Go client for the Zulip REST API, generated from the OpenAPI document Zulip publishes. If you only want to use the client from an agent, read [.agents/skills/go-zulip/SKILL.md](.agents/skills/go-zulip/SKILL.md) instead; this file is about changing the code.

## Architecture

One generated package, `zulip`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads `https://raw.githubusercontent.com/zulip/zulip/main/zerver/openapi/zulip.yaml` to `api/openapi.yaml` → oapi-codegen with `config.yaml` and `scripts/client.tmpl` → `client.gen.go`. No spec patch is required.

## Stack

- Go 1.26.10.
- oapi-codegen, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, the client generation template, lint and security scan scripts.
- `api/`: the downloaded spec, gitignored.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The base URL includes `/api/v1`. Use the user's trusted Zulip server, never a fixed public server for authenticated requests.
- Authentication is HTTP Basic with email as username and API key as password. The generated client requires a request editor to set it.
- Zulip uses URL-encoded request bodies for many operations. Use the generated form request types or the raw-body method with the exact content type the endpoint expects.
- `scripts/client.tmpl` overrides the generator's client template through `config.yaml` `user-templates`. It JSON-encodes composite form values and honors `application/json` field encoding, including quoted strings. Other scalar strings remain plain. The default runtime form encoder drops union fields and indexes arrays. Default query serialization works with the spec's JSON declarations and stays unchanged. Change the template, then regenerate; never patch `client.gen.go`.
- Method names come from operation IDs, such as `get-own-user` becoming `GetOwnUser`. Check generated signatures before changing examples.
- Non-2xx responses do not automatically become Go errors. Check response status and the relevant decoded status field.
- `make generate` always downloads the current spec, so it can change the client even when nothing here changed. Review the generated diff.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When checks fail, Claude edits the repository, but a fix may not touch `fix_protected_paths`: the workflows, Makefile, `AGENTS.md`, `.agents/rules/`, lint, security and spec download scripts and their configs. A problem requiring changes there needs a manual fix.
